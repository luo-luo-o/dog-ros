# 机器狗模型来源

模型来自本地 `rlsar/src/rl_sar_zoo/dog_description` 的 CAD 资产。上游 SuperMimic 训练项目用 13 个 STL 生成了修正后的 URDF 和 MJCF。原生成入口为训练仓库中的 `scripts/robots/port_dog.py`，这里随工作空间携带生成后的模型。MuJoCo 场景在 `src/dog_sim/model/dog.xml`，运行时使用此处的网格。

原 CAD 坐标为 X 右、Y 后、Z 上。导出模型采用 X 前、Y 左、Z 上。导出时依次应用源关节与网格位姿，并在标称站立姿势的各连杆坐标系内表达。髋外展沿 +X，大腿和小腿俯仰沿 +Y。髋到大腿关节偏移的绝对值约为前后 16.71 毫米、横向 16.71 毫米、向下 23.09 毫米。大腿有效长度为 0.12 米，膝到足的平面长度为 0.139291 米，足端相对膝向内约 27.151 毫米。

模型以躯干替代仅作 CAD 标记的 `base_link`，将固定足合并入小腿，总质量约 2.0142 千克。各连杆惯量为仿真估计。实物策略部署前需重新测量质量、质心和惯量。

原控制器记录的连续力矩为 2.2 N·m，堵转力矩约 3.578 N·m，空载转速约 4.717 rad/s，关节转子惯量为 0.01 kg·m²。仿真使用 40/1 的位置 PD 及 2.2 N·m 连续力矩限幅。仿真模型中大腿碰撞使用两块叉板和横向圆柱，躯干与大腿沿用四组碰撞排除。URDF 通过三个箱体近似躯干以留出髋部开口。

模型关节范围用于仿真运动学，选取了能覆盖重定向膝后弯分支的角度。实物限位以测量值为准。标称站立高度约为 0.22357 米。
